## What it does

<CardGrid>
	<Card title="Distributed fields" icon="puzzle">
		A field on the nodes of a 1D, 2D or 3D grid, one or several components per node, split over MPI ranks with halo nodes (mpiarray's layout, simgeometry's grid).
	</Card>
	<Card title="Gather and scatter" icon="random">
		Interpolate the field at marker positions and deposit marker values onto the nodes with cloud-in-cell weights, exact transposes of each other.
	</Card>
	<Card title="Compiled kernels" icon="rocket">
		Pyccel with OpenMP on the CPU, CUDA for CuPy arrays, Metal on Apple silicon, a NumPy fallback: the same arguments for all.
	</Card>
	<Card title="Fields as values" icon="seti:pipeline">
		Arithmetic, ufuncs, gradients, cross and dot products, smoothing, reductions over all ranks, xarray evaluation, plots through plasma-plots, NetCDF files.
	</Card>
</CardGrid>
