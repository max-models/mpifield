This demo runs mpifield in your browser with [Pyodide](https://pyodide.org) (Python compiled to
WebAssembly), on the NumPy versions of the kernels: there is no compiler in the browser, so
the Pyccel kernels are not built.

The markers are drawn from the density $n(x) = 1 + 0.5\cos x$ on a periodic domain of length
$2\pi$, each with the weight $2\pi/N$, and deposited onto the grid nodes with the linear
(cloud-in-cell) or the quadratic weighting; the binomial filter `[1, 2, 1] / 4` smooths the
result. The total weight is conserved exactly, whatever the settings. The deposit is noisy, by
about $\sqrt{\text{nodes}/N}$ per node: more markers or fewer nodes reduce the noise, and the
quadratic weighting and the smoothing damp it further, at the price of flattening the peak
when the grid is coarse.
